## What this is

[ZuBerlin 2025](https://zuberlin.city) — the Futura Garden: an immersive residency on a Berlin
rooftop, bridging humanity and technology during Berlin Blockchain Week. The garden's knowledge
shouldn't compost — so it got a pit.

- **13 sessions** with the full Esmeralda genesis UX: Knowledge Transponder modal, synced glowing
  transcripts (as the harvest fleet lands them), tap-to-seek, deep transcript search
- **5 theme tabs** (🌅 Opening · 🔐 Cryptography · 🧙 Data · 🔗 Interop & Protocol · 🌱 Society & Jam)
- Cryptography days, interop, protocol & MEV, "25 zkVMs: too few or too many?", and the garden jam 🎻
- Berlin-dawn botanical palette (dusky violet + fern green + burnt orange), Orbitron
- **≈ \$0 infra** — static site, recordings stream from the source Drive, transcripts + audio on R2

🔇 **Silence canon:** this pit has no music player. Pits listen, they don't sing.
